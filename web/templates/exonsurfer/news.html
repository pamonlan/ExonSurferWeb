v1.4.0
Major Update: 9 New Species & Non-Vertebrate Fixes

This release greatly expands species coverage, fixes primer design for organisms with non-standard exon ID naming conventions, and centralises all species configuration into a single file.

ExonSurfer Core
  • NEW 9 New Species: Xenopus tropicalis, Gallus gallus, Sus scrofa, Macaca mulatta, Caenorhabditis elegans, Saccharomyces cerevisiae, Solanum lycopersicum, Zea mays, and Glycine max.
  • NEW pyensembl patch: Registered X. tropicalis, Z. mays, S. lycopersicum, and G. max in pyensembl's species registry, enabling clean gene symbol resolution for these species.
  • FIX Junction key separator: Changed from "_" to "|" in ensembl.py, chooseTarget.py, and construct_cdna.py. Fixes TypeError: cannot unpack non-iterable NoneType for species whose exon IDs contain underscores (e.g. yeast YFL039C_mRNA-E1, C. elegans ZK617.1a.1.e1).
  • FIX FASTA line-wrapping: Chromosome sequence files from Ensembl use 60-character line wrapping. Passing wrapped sequences to Primer3 caused a ValueError: Input line with no '='. Fixed by stripping headers and joining lines on read in construct_cdna.py and ensembl.py.
  • FIX Chromosome existence check: MASKED_SEQS() was always looking for _1.txt regardless of species, causing spurious re-downloads every run for species with Roman numeral chromosomes (S. cerevisiae, C. elegans). Fixed via a FIRST_CHR_CHECK dict in resources.py.
ExonSurfer Web
  • NEW Centralised species config: All species metadata (display names, assemblies, chromosome lists, API URLs, DB paths) now live in a single species_config.py. Adding a new species requires editing only that file.
  • IMPROVED Dynamic species form & dropdown: The species selector, gene input fields, and JavaScript API calls in index.html are now generated automatically from species_config.py — no more hardcoded HTML per species.
  • IMPROVED prepare_species_db.py: New script to automate BLAST DB and chromosome sequence preparation for any species, with FTP auto-discovery of chromosome files and Zenodo-ready zip output.
  • NEW ΔΔCt qPCR Analysis: New built-in module to perform delta-delta Ct analysis directly from Excel Ct results — no R required. Features include: technical replicate averaging, efficiency-corrected fold change calculation, Welch t-test p-values with significance stars, asymmetric error bars, interactive Plotly bar charts with per-gene subplots, customisable group colours and ordering, and a downloadable results table.
